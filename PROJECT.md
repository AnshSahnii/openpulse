# OpenPulse Project Brief

## Goal
Build a portfolio-ready platform for discovering, evaluating and bookmarking open-source repositories.

## Stack
- Frontend: React + TypeScript
- Backend: FastAPI + Uvicorn
- Database: PostgreSQL + SQLAlchemy
- Integration: GitHub REST API + HTTPX
- Auth: JWT
- Deployment: Docker Compose

## MVP complete
The repository contains a runnable MVP with search, repository persistence, authentication, bookmarks, dashboard UI, API docs, caching and Docker configuration.
